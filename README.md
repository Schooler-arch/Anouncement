# School Announcement Webpage

A lightweight, festive HTML/CSS announcement template designed to display full-screen holiday wishes and school updates.

## 📌 Overview

This project provides a simple, responsive web page styled with custom CSS to display school-wide holiday greetings. It features custom typography, glowing text effects, centered flexbox layout, and autumn-themed color schemes.

## 🚀 Usage

1. **Save the Code**: Ensure the code is saved in an `index.html` file.
2. **Open in Browser**: Double-click the `index.html` file or open it in any web browser to view the announcement.
3. **Customize**: Edit the following elements directly inside `index.html`:
   - `<h1>` tag: Change the main heading message.
   - `<p>` tags: Modify the announcement details or signatures.
   - `.emoji` container: Update the displayed icons for different holidays.

## 🎨 Theme Details (Thanksgiving Edition)

- **Background Color**: `#2b1b17` (Dark Chestnut)
- **Primary Accent**: `#d35400` / `#e67e22` (Pumpkin Orange)
- **Font Stack**: `Arial Black` (Headings), `Arial` (Body), `Comic Sans MS` (Signature)
